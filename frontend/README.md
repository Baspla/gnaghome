# Gnag Home Frontend

The frontend uses Svelte 5 and SvelteKit, styled with Tailwind CSS, Skeleton UI, Bits UI, and Lucide icons. Centrifugo uses static access-level subscriptions to `public` and the current user's `user:<userId>` channel. The GatewayManager dispatches validated thin platform events by type; visible consumers match `entityId` before refetching canonical data through the backend API.
